# 质量治理

## 当前质量门禁

| 检查 | 命令 | CI 策略 |
| --- | --- | --- |
| 类型检查 | `npm run typecheck` | 必须通过 |
| 单元测试 | `npm test` | 必须通过 |
| lint 基线 | `npm run lint:baseline` | 错误或警告总数增加即失败 |
| 完整 lint 报告 | `npm run lint` | 用于定位并清理存量问题 |

`scripts/eslint-baseline.json` 固化了 2026-08-25 的初始问题数。基线只能下降；确需上调时，必须单独提交并在 PR 说明新增规则或外部工具变化。

## 治理阶段

1. 冻结：不得增加 lint 错误或警告。
2. 清理：按目录或规则族修复存量问题，并同步下调基线。
3. 强制：基线清零后，将 CI 改为直接执行 `npm run lint`。

新代码必须遵守开发规范；历史问题不能成为继续新增同类问题的理由。

## 文档更新触发条件

下列变更必须在同一提交中更新文档：

- `package.json` 的依赖版本或 scripts；
- `src-tauri/tauri.conf.json` 的打包目标、CSP、更新器或应用版本；
- 缓存容量、存储模式、导出或渲染协议；
- 面向用户的功能、限制或发布内容。
